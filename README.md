# Rule Engine

## Overview

A simple rule-based decision engine.

---

## Features

* Define rule sets
* Evaluate input based on rules
* Return decision output

---

## Files

* `rules.py` → defines rules
* `engine.py` → applies rules

---

## Usage

```bash id="n7x2qp"
python engine.py
```

---

## Example Output

```id="t4k8rs"
Age 22: High
Age 35: Medium
```

---

## Use Case

* Risk scoring systems
* Business rules engines
* Decision-making systems
